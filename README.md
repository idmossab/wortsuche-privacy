# Wortsuche

Wortsuche is an offline word-search game for learning German vocabulary. Find the hidden words in the letter grid and learn their meanings and examples.

## Features

- Four German learning levels: A1, A2, B1, and B2
- 10 stages in each level
- Word-search puzzles organized by topic
- Word meanings and example sentences
- Progress and scores saved locally on the device
- Works offline
- Arabic, German, and English interface options

## Built With

- Flutter
- Dart
